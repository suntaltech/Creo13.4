# PTC 支持材料离线审核包

日期：2026-11-12（北京时间）。

本包包含校正后的支持请求草稿、27项证据索引、复核状态及12项已匹配历史R10附件的校验记录。它不是包含27项证据实体的完整复现包，不含DLL、SDK、R11 ETL或未收到的R11结果文件。

建议先阅读 PTC_SUPPORT_REQUEST_REVIEWED.md，再查看 PTC_EVIDENCE_INDEX_REVIEWED.json。索引中的“actually_attached_to_PTC_submission=false”表示尚未形成/发送PTC附件，不代表对应本机文件一定缺失。源文件绝对路径在此可转交副本中改为相对占位，原复核稿未修改。

完整性：先用ZIP旁的.sha256验证压缩包，再用包内SHA256SUMS验证各文件。本包未联系PTC，未部署、修改插件、配置或模型。R11小文件待补证清单见支持请求末段。
