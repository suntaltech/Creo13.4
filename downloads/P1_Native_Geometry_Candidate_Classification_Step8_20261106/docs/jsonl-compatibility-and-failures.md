# Step7兼容、计数与失败

独立geometry-sampling-step8-UUID.jsonl，CREATE_NEW；原基础/采样/质量/候选池/队列/空间/配对/distanceSchema保持，collectorStep=STEP_8，追加classificationSchema=P1_NATIVE_LOCAL_DISTANCE_CLASSIFICATION_V1和interfaceReviewSchema=P1_NATIVE_READONLY_API_REVIEW_V1。原字段类型与门禁不改，严格消费者按新增标识分流。

新增CANDIDATE_CLASSIFICATION_STARTED、PAIR_CANDIDATE_CLASSIFICATION、CANDIDATE_CLASSIFICATION_SUMMARY。每个已选择的至多32对都有一条分类，包含独立维度标签、方向、最小/最大已有点距、零/正/异常记录数、法向提示、摘要一致性和probeCoverageState。标签可重叠，不能求和得候选总数；不把未访问的对按0距离处理。

分类旁路观察本运行已写出的间隙/距离/摘要，不读外部历史文件、也不修改旧记录。原采样attempts/acceptedSamples、域链计数和距离见证数保持独立；分类标签或SDK目录记录都不是新样本或新见证。

无摘要/未探测/预算中止时保留UNKNOWN/部分覆盖标签，不将它们和完成有限探测但无见证混淆。负数/非有限距离、面方向不符、摘要数量不一致标数据问题；classificationInvalidPairs或observerOverflow会阻止整轮升级完整。摘要未提供方向计数时只比较已提供的见证总数，方向比较另记UNKNOWN_NOT_IN_PAIR_SUMMARY；不能把总数一致解读为未提供方向的认证。

新增SDK_READONLY_INTERFACE_REVIEW_STARTED/ITEM/SUMMARY，表示对所供SDK的静态签名目录，suppliedSdkSha256是离线输入身份，不是当前运行JAR独立散列认证。所有新候选接口的runtimeInvoked/readOnlyContract/licensing/occupancy/occlusion证明均false；不能按“列表里有此方法”自动启用调用。

最终COLLECTION_SUMMARY增加classificationState/invalidPairs/observerOverflow和interfaceReviewState等。MULTI_LABEL_REVIEW_ONLY及STATIC_SUPPLIED_SDK_SIGNATURE_REVIEW_ONLY只说明本阶段输出，绝不代表材料/遮挡或最终厚度完成。原revision未知、身份变动、READ_EXCEPTION/READ_UNAVAILABLE、阶段中断继续按原严格PARTIAL/UNKNOWN解释。

日志或IO异常导致摘要缺失时不能补造成功或用0填未知。分类上限32对，SDK目录12项，不引入无界循环、后台/native线程或网络操作。原生双INSIDE、精确UV、XYZ数值回读与非共线门槛均不变。
