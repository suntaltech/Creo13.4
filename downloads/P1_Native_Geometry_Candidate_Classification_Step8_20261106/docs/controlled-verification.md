# 后续受控核对

云端只完成编译/静态接口/纯分类回放，未部署、注册、执行Creo、材料或射线调用。后续在已有受控范围执行。

1. 校验ZIP.sha256、SHA256SUMS、manifest、实际SDK/Java25及21个class/薄JAR身份。新Step8目录/类/消息/命令，不覆盖Step7、生产注册或Ribbon持久化；模板路径占位符不可直接用，记录现场加载文件散列。
2. 核对原Step7采样基线：126组非共线、原16面积恢复、原32最小点距边界、666点/2702尝试、解析与局部见证的门禁/预算。新增分类不能掩盖旧阶段退步；单位/模型变化应保留未知和严格身份状态。
3. 对实际32对（或因限制未完成的计划）核对六类标签与probeCoverageState。多标签可同时出现，10 mm仅用于mm审阅，原生点距不被修改/丢弃；其他单位应UNKNOWN。
4. 按每条原局部距离重算零/正、min/max、A→B/B→A、法向提示与摘要计数。无摘要/未探测不得标成已证明无对应；故意伪造/改动模型验证数据不属于本清单。
5. 核对SDK目录显示12项静态风险及来源SDK散列，不做新的WModel/WSolid强转、射线、投影、干涉或GetMaterial试调用。本包只输出未确认项，实际58项PTC调用面应与Step7一致。
6. 所有分类应materialOccupancyVerified=false、occlusionVerified=false、globalWallThickness=NOT_ASSESSED、等厚证据不足。不据1.2 mm记录或多次重复位置设定全局厚度，不从距离<=10 mm推广可转。
7. 读取最终COLLECTION_SUMMARY，revision缺失不以版本戳替代，dirty=false不证明独立零写入。异常或状态变化时停止后续测试保留原件，不Save/Undo/再生/改精度/自动重试，不转换或改Web、业务命令、Ribbon。
