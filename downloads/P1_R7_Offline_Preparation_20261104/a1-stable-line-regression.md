只整理已给出的稳定功能与待核对项，不修改A1代码、页面、参数存储或发布包。未提供本机权威A1稳定源码/参数定义，本轮不从P1候选推断稳定实现，也不填写回归通过。

| 规则 | 未来核对内容 | 当前结论 |
|---|---|---|
| 前缀+序号 | 参数解释、预览与实际名称、对象范围、失败提示 | UNVERIFIED，按稳定基线核对 |
| 保留原名+后缀 | 原名保留、后缀应用、预览与实际一致性 | UNVERIFIED |
| 前缀+序号+后缀 | 三段组合、序号行为与既有规则一致 | UNVERIFIED |

不自行规定序号初值、位数、冲突处置或参数默认值；这些须由稳定版本行为/规格提供。参数记忆按现有持久化边界核对：页面重开、模式切换、会话重启分别记录，不创造新缓存键或修改保存方式。

| 模式 | 稳定命令的核对重点 |
|---|---|
| no_model | 是否按稳定基线显示守卫，不误进行模型处理 |
| assembly | 批量重命名规则、预览、守卫和范围 |
| part / sheetmetal | 是否按稳定基线导航或守卫，不推断装配能力 |
| drawing / other | 不支持模式的既有提示和URL参数边界 |

SISWBatchRename、SISWSheetMetal、SISWAbout分别保留自身记录与requestId；名称相同不证明当前加载的是稳定class。URL参数、图标和页面责任以本机稳定基线为准，不能把P1候选的URL或WFC适配路径当成A1规格。

禁止合入SISWSheetMetalConvert、P1未验证类、浏览器桥接写模型路径或OTK许可假设。批量重命名本身可能改变模型身份，未来功能回归需独立授权；本文件只准备清单，没有执行或发布。
