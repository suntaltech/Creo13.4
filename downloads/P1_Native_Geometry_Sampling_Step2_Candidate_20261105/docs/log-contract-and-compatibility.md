# JSONL兼容性与覆盖率

## 独立运行，不修改Step1

新应用类和命令ID、消息文件均独立；输出到同一可配置证据目录时使用geometry-sampling-UUID.jsonl及CREATE_NEW，不覆盖geometry-UUID.jsonl。默认user.home/CreoReadOnlyGeometry或P1_READONLY_GEOMETRY_LOG_DIR，证据文件写入不等于保存模型。本轮不生成实际采集日志。

保留基础schema=P1_NATIVE_READONLY_GEOMETRY_V1及事件COLLECTION_STARTED、模型前后、单位/精度、DEFAULT_BODY、BODY、SURFACE、COLLECTION_SUMMARY等字段名称与类型；增加collectorStep和samplingSchema标识。SURFACE.sampling改为SEE_STEP2_EVENTS、unsampledReason说明点数据不在基础SURFACE行；summary.samplingCoverage仍为字符串，指向新增采样摘要，不从旧字符串改成对象。新step2SamplingCoverage是额外字段。旧文件和Step1代码完全不改，严格旧枚举消费者需按新标识分流，不向冻结旧schema强塞PASS。

## 新事件

SAMPLING_STARTED记录目标范围、已观察目标数、分母是否已知和上限。只有modelListed且真实类型PLANE/CYLINDER进入目标；其他类型仍有基础SURFACE行，未当作目标失败或假定不薄壁。

POINT_NORMAL_SAMPLE记录surfaceId/bodyId及observedBodyIds、体归属完整性、真实类型、attemptOrdinal、请求/返回UV、两次VerifyUV代码、原始/单位法向、原生方向代码、点与单位、坐标来源和sampleAccepted。归属未知不会伪造default body；原样点/法向也不自动成为可用于实体厚度计算的已认证样本。identityDisposition在点记录中为PENDING_FINAL_COLLECTION_SUMMARY。

SAMPLE_REJECTED记录候选序号、UV、拒绝原因和可用placement代码；原生异常通过基础READ_EXCEPTION关联同requestId。请求/返回UV不一致仅记录拒绝原因，不使用返回点或自动修正候选。

SURFACE_SAMPLING_SUMMARY记录目标3点、已尝试数、接受数、拒绝原因统计与停止原因。SAMPLING_TARGETS_NOT_ATTEMPTED列未开始目标及全局停止原因。SAMPLING_SUMMARY记录总体统计，可先于最终模型身份核对写出，因此其POINT_QUOTAS_MET_ONLY仅是点配额，不是整轮接受或成功。

## 覆盖率

分母仅在模型曲面枚举、逐面类型读取和基础记录均完整时确定为本轮全部已列举PLANE/CYLINDER数；否则targetDenominator=UNKNOWN，不能把部分已知目标当全部。body-only曲面不混入本采样范围。observedTargets保留已识别目标数。

faceAnySampleCoverage统计至少1个接受样本的目标面；faceQuotaCoverage统计取得3点的目标面；pointQuotaCoverage为接受点数/(目标面数×3)。未知分母ratio=null，零目标ratio=null并标NO_TARGET_SURFACES，不显示100%。它们不表示均匀面积覆盖、孔边界覆盖或等厚覆盖。单面不足3点或配额分母未知使整体保留PARTIAL；原生异常仍计errors。

## 身份增强不替代revision

MODEL_BEFORE/AFTER增加versionStamp及versionStampSource=Model.GetVersionStamp、revisionSource=Model.GetRevision。GetRevision仍直接保留SDK值，null不填CREOSON数字或versionStamp。原有严格revision身份条件不变，因此本样本可能继续identityStableWithinObservedFields=false、metadataComplete=false、PARTIAL。

STEP2_IDENTITY_CONTEXT及summary.versionStampContextMatches单独说明前后原模型/当前模型的句柄、文件名、版本戳和dirty字段是否一致；缺失戳/dirty即不确认。它是有限字段观察，不证明原生内存内容从未变化，也不把已dirty模型当成未修改模型。版本戳变化增加身份变化标记，样本最终disposition为INVALIDATED_OBSERVED_MODEL_CHANGE；戳等观察一致时仍不称独立零写入证明。

thinWallShapeAssessment/uniformThicknessAssessment继续证据不足，modelWriteAbsenceIndependentlyProven固定false。只有最终COLLECTION_SUMMARY结合身份上下文可判断样本是否应继续人工审阅；不得只看一条sampleAccepted或采样配额摘要。
