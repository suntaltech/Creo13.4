# 新队列与结果口径

## Step4基线及策略调整

Step4原48组中16改善、32未改善；32组的1024个追加探测均被原生记录标为边界。前32个候选全部来自原边缘队列前4层，内部Halton未到达。第五步修正顺序及预算，保持原生门禁和数值阈值，不通过增加边缘层、放宽边界或改精度解决。

新队列从本次初始3个已验证有效点的UV出发，使用冻结初始种子生成一次计划，不把新追加点再扩展为无界搜索。局部偏移按UV范围跨度的1/64、1/256、1/1024、1/16四种尺度，在正U、正V、负U、负V方向提出候选。各尺度/方向轮换初始种子，优先16候选覆盖四尺度/四方向；后备种子仅补充重复/矩形外提议，不增加原生探测预算。这些比例是采样策略，不是模型容差或长度单位。

内部候选来自Halton(base2/base3)序列，有限64个提议中按实际UV去重后选至多8个；它们不自动属于修剪域。边缘候选只有既有1/32一层8个位置，优先安排Step4观察有用的4个位置，不按面ID套用成功结论。没有新增边缘层。

计划按 LOCAL_INSIDE_OFFSET → INTERNAL_HALTON → LOCAL_INSIDE_OFFSET → EDGE_SINGLE_LAYER 循环8次，分别预算16/8/8。对原48组真实种子回放计划均为完整32，前4槽可达三策略。这里的槽指计划位置，不能据此断言运行中已经探测。

每次取候选都检查严格位于有限参数矩形内部、实际UV不与已尝试位置或已计划候选重复；不夹紧、外推、周期规范化或生成XYZ。某策略提议无法表示/去重后不足时，该槽不以更多边缘探测填满，因此计划可不足32；日志保留真实planned数。局部已知INSIDE锚点也不是邻域全有效的证明，仍逐点原生VerifyUV。

## 不变部分及停止规则

初始3点仍按Step4的基础25候选及原4面200候选细化取得。质量池仅在PLANE初始三点非共线标志不为true时启用，所以本案例仍可能对原48组启用，不只32组；先前16组也需回归核对。原非退化78平面和96圆柱无质量池新增探测。

每面质量追加≤32、池≤9、最终≤3，全轮≤300目标面/3000尝试/900最终点/30秒软预算不变。池满可提前停止，即使后部包含更好候选也不会无限探测；全局预算和单次原生调用不能硬中断的约束保持。计划可达不等于实际可达。

固定q=|AB×AC|/最长边²门槛仍为256×ulp(1.0)=5.684341886080802e-14。选择器保持Step4：只考虑通过固定门槛且相对池尺度的面积分数不低于原3点的组合，优先最大面积分数、同分最大最小点距，余同分按索引。没有合格组合或数值未知保留原点并报告未改善，不降低阈值。该阈值不是官方模型公差，三角形或UV包围矩形都不是材料覆盖。
