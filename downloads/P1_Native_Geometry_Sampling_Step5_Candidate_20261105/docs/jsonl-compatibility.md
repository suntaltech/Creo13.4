# Step4兼容与策略日志

新独立geometry-sampling-step5-UUID.jsonl，CREATE_NEW不覆盖旧日志。保留原基础schema、samplingSchema、samplingQualitySchema及selectionSchema=P1_NATIVE_PLANE_POINT_POOL_V1，collectorStep=STEP_5，追加queueSchema=P1_NATIVE_MIXED_UV_QUEUE_V1。旧事件/字段类型和最终点/拒绝口径保持Step4；严格旧消费者按collectorStep/queueSchema分流。

新增QUALITY_CANDIDATE_QUEUE包含plannedCount、strategyOrder、knownInsideSeedAttemptOrdinals、orderPolicy和strategyStats，描述完整参数计划，不是原生执行记录。PLANE_POOL_SELECTION和SURFACE_SAMPLING_SUMMARY中的strategyStats是实际尝试与最终选点后的计数。三策略分别记录planned、attempted、nativeValidCandidates、nativeGateOrUniquenessRejected、finalSelected、validButUnselected。正常完成面：attempted=nativeValidCandidates+nativeGateOrUniquenessRejected，nativeValidCandidates=finalSelected+validButUnselected，各策略attempted之和=qualityAttempts。基线点不计入这些质量策略统计；其未入选数仍包含在原面/全轮validButUnselectedCandidates中。

每个接受/原生拒绝/有效未选记录追加candidateStrategy；BASE及TARGETED_REFINEMENT仍保留原candidatePhase，质量追加仍为QUALITY_POOL、再按candidateStrategy细分。局部记录knownInsideSeedOrdinal（1起始，指初始三点列表）和localOffsetRangeFraction，非局部为NOT_APPLICABLE。通过初始尝试序号及池中间事件关联锚点。它们是提议来源，不是新的原生有效性证据。

POINT_NORMAL_POOL_CANDIDATE是中间记录，不计为最终点/额外探测。POINT_NORMAL_SAMPLE仍只在最终选中时输出，每面≤3，candidateEvaluationTimestamp是取值时间，timestamp是输出时间，attemptOrdinal可能因延后输出而非事件顺序递增。

SAMPLE_REJECTED中原生边界/域外等原因不变；VALID_NATIVE_CANDIDATE_NOT_SELECTED_BY_QUALITY仍标candidateNativeValid=true和FINAL_QUOTA_SELECTION_NOT_DOMAIN_VALIDITY，不能统计为原生无效。正常完成面仍attempts=acceptedSamples+rejectedAttempts，attempts=baseAttempts+refinementAttempts+qualityAttempts；中途异常/IO终止不能凭中间事件补造终局。

质量不足、未知或限制仍保留PARTIAL/UNKNOWN；versionStamp不替代revision，100%点数配额不代表质量/面积/等厚覆盖。没有改变身份检查或零写入证明边界。
