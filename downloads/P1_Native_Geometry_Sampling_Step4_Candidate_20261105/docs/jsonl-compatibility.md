# JSONL兼容与整合口径

独立geometry-sampling-step4-UUID.jsonl，CREATE_NEW，不改Step3日志。保留schema=P1_NATIVE_READONLY_GEOMETRY_V1、samplingSchema=P1_NATIVE_GEOMETRY_SAMPLING_V1、samplingQualitySchema=P1_NATIVE_GEOMETRY_SAMPLING_QUALITY_V1及原事件字段类型；collectorStep=STEP_4，新增selectionSchema=P1_NATIVE_PLANE_POINT_POOL_V1。属于追加扩展：严格固定枚举的旧消费者需按collectorStep/selectionSchema分流。

POINT_NORMAL_SAMPLE只输出最终入选的至多3个原生点，每个都有原来的门禁/法向/单位字段。采集先暂存再在面处理结束时输出，因此事件timestamp是写日志时间，candidateEvaluationTimestamp是取值时间；事件顺序不保证按attemptOrdinal递增，ordinal仍在同一面内唯一并标识实际尝试。candidatePhase新增QUALITY_POOL，BASE及TARGETED_REFINEMENT保留。

新增PLANE_QUALITY_POOL_STARTED、POINT_NORMAL_POOL_CANDIDATE、PLANE_POOL_SELECTION。池候选是中间证据，不得再次累计为最终样本或原生尝试。PLANE_POOL_SELECTION包含初始/最终质量、入选索引/attempt、探测量、停止原因与数值改善标志。PLANE_SAMPLE_QUALITY始终根据最终入选点重算，并带初始质量标志、池启用与阈值未变字段。

SAMPLE_REJECTED保留原生/重复点等拒绝原因；新增VALID_NATIVE_CANDIDATE_NOT_SELECTED_BY_QUALITY，placement=INSIDE且candidateNativeValid=true，rejectionStage=FINAL_QUOTA_SELECTION_NOT_DOMAIN_VALIDITY。这表示原生有效但未入选最终3点，不能统计为原生域外/边界或无效点。旧acceptedSamples明确是最终点；rejectedAttempts是未入选最终点的尝试总数，包含上述有效未选，保持完成面attempts=acceptedSamples+rejectedAttempts。新增validButUnselectedCandidates与nativeGateOrUniquenessRejectedAttempts区分口径；后者仍可能包含求值异常/预算拒绝，名称不能解读为只包含域外。

逐面attempts=baseAttempts+refinementAttempts+qualityAttempts，后两个旧字段意义不变。nativeValidCandidates=当前面池大小，validButUnselectedCandidates=池大小-最终点数。SAMPLING_SUMMARY统计qualityPoolFaces/improved/unimproved及最终非共线/退化/未知组。配额达标与质量改善独立；qualityObjectiveStatus只涉及实际启用池的面，不能据此声称未访问面也合格。全轮完成还要求没有已启用但未改善的面，身份/revision等原有严格条件也保留。

记录错误/未知/限制不改为成功。最终身份以COLLECTION_SUMMARY为准，revision null仍可导致PARTIAL，versionStamp不替代它。不计算厚度，不报告等厚。中途中断/IO失败时可能只有池候选而没有完整终局计数；必须视为不完整，不凭中间记录补造结果。
