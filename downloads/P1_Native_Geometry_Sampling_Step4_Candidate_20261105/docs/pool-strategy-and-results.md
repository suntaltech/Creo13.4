# 候选池、数值策略与48面结果

初始选点顺序与Step3一致：基础最多25候选；只有200002100.prt且真实PLANE、ID2710/2738/2752/2843在基础不足3点时继续原200候选细化。模型名/ID匹配不是独立身份认证，不能为命中策略修改模型。已达3点的非退化平面和圆柱面不启动质量池。

退化/未知的三点平面先保留初始3点，追加确定性UV种子。队列先使用Step3边缘偏置的15×15层次种子并排除已尝试实际UV，再附64个Halton(base2/base3)内部种子；最多只探测前32个未重复位置，达到9个原生有效XYZ点即可停止。队列后部Halton不保证在32次内执行。原生修剪域仍由VerifyUV判断，参数矩形内部不自动是有效材料。不会插值生成XYZ、跨面借点或从失败点推断成功。

每个池仅存同一面的最多9点，从中枚举最多C(9,3)=84组三点。非共线仍用Step3 q=|AB×AC|/最长边² > 256×ulp(1.0)，阈值5.684341886080802e-14保持不变。这只是浮点数值规则，不是官方模型容差、厚度或面积覆盖门槛。

符合上述固定阈值的三点还必须满足其 |AB×AC|/池内最大两点距离² 不小于基线3点的相同分数，避免仅为跨过质量标志而牺牲空间面积。首先最大化该面积分数，再以最小两点距离/池内最大距离作同分时的排序，剩余同分按索引顺序确定。最小两点距离不是额外的单调改进保证；与面积分数不同，最终q也不是最大化目标。没有合格组合、数值范围未知或候选不足时保留基线，不调低阈值。

上限：每面最终仍至多3点；质量池至多9点、质量追加探测至多32。普通平面总尝试至多57，案例4面至多257，圆柱仍至多25；全轮仍300目标面、3000候选尝试、900最终点、30秒软预算。单次SDK调用无法被软预算中断。全局尝试不足可使后续面未采样，应保留限制/PARTIAL，不能保证所有模型都保持原配额。对已知48组，本策略额外探测上界1536；与已知Step3的1166相加为2702，这是预算推算，非Step4实测尝试量。

Step3实测126个平面中78组数值非共线、48组退化。新候选未执行Creo采样，因此不能给出48组改善比例；逐面表全部NOT_EXECUTED/UNKNOWN。附带旧点回放只重算原三点，结果仍78/48、替换0，证明没有通过修改阈值在旧点上制造成功。真实改善必须同时核对相同模型身份、面ID、最终点、原生门禁及最终质量；真实结果可为改善、未改善、未知或未尝试。

三点三角形可跨孔和修剪外部，面积分数与UV分散都不代表材料覆盖，更不能推出等厚、相对面距离或转换可用。法向保持SDK原方向，不自动翻转为实体外法向。
