# 第五步后路线建议（未实施）

当前数值非共线目标已由本轮记录支持：剩余32组改善，原16组保持非共线，126组全通过原阈值。应冻结原候选和本轮证据，不继续通过降低阈值追求表面状态变化；整体PARTIAL和等厚证据不足保持。

下一轮如继续提高空间分布，建议最小范围围绕原16组回退：

1. 明确验收是“同轮初始三点不退步”还是“相对上一轮已选三点的分散指标不退步”。现行代码仅保证前者；原16组三角形面积降至28.93%，不能据全组非共线声称后者已满足。
2. 优先研究受限池的停止/保留策略，例如在总探测≤32、池保留≤9和全局上限内为不同策略保留探测机会，或对已读有效候选进行有界替换。所有实际点仍须新一轮原生验证，不得把旧日志坐标直接当当前模型有效点；未经任务明确不实施。
3. 若继续探测后替换池中点，应完整保留原生有效但淘汰/未选的处置和来源，更新计数守恒与中间日志，避免超过9保留点或重复计最终点。不得靠接受边界/域外、改模型精度、无限增大预算或降低阈值改善结果。
4. 下一轮分别复核32面非共线保持、16面空间分散比较、174其他面与4个细化面回归；同时报告q、面积/距离与实际策略探测，参数矩形或三角形不是材料覆盖。
