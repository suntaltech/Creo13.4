# 日志与覆盖率

一次真实点击才创建UUID requestId及geometry-<requestId>.jsonl；无预置运行ID或成功样例。默认写到user.home/CreoReadOnlyGeometry，或未来操作者通过P1_READONLY_GEOMETRY_LOG_DIR指定证据目录。创建目录和证据文件是本地文件写入，不是保存模型；禁止将输出目录指向模型/生产配置目录。文件CREATE_NEW不覆盖旧证据，每行UTF-8 JSON并flush，同时镜像到System.err的[P1GEO]前缀日志。结构化文件本身是纯JSONL。

打不开证据文件时不会开始模型采集；中途日志I/O失败会使流程报错，可能没有终结记录。末尾缺COLLECTION_SUMMARY或关闭失败的运行不能当成完整证据。窗口/消息反馈失败也记录，errors含读取异常与数据/UI问题条数，不是“失败SDK调用唯一数量”。unknownReadValues记录返回null的读取，不等同errors。

事件包括COLLECTION_STARTED、READ_UNAVAILABLE/READ_EXCEPTION、DATA_ISSUE、MODEL_BEFORE/AFTER_ORIGINAL/AFTER_ACTIVE、UNITS_AND_ACCURACY、DEFAULT_BODY、BODY、SURFACE及COLLECTION_SUMMARY。真实异常堆栈作为JSON字符串保留，换行转义，原件分享前按实际敏感内容脱敏，不补造堆栈。开始/结束提示仅指流程状态，不能代替summary或覆盖率。

BODY按模型枚举槽位记录，默认体fallback独立scope。surfaceReferenceCoverage的completed是已访问列表槽位，不代表每项读取成功；失败和未知关联还需看READ_EXCEPTION、bodyMembershipEnumerationComplete及面字段覆盖。重复体/面ID均记录问题，不能用百分比掩盖。

summary中bodyStateCoverage分母是ITEM_BODY枚举总槽位，分子是这些槽位成功读取IsSheetmetal的个数，fallback不计入；modelSurfaceRecordCoverage分母是ITEM_SURFACE枚举槽位，分子是已输出的唯一modelListed曲面记录；modelSurfaceRequiredFieldCoverage只计类型、有效面积、唯一体关联及成员枚举完整的modelListed记录。未知分母不给100%，空分母ratio=null且标EMPTY_NOT_PERCENT_COMPLETE。重复枚举或失败会令记录数低于槽位总数。

另列模型曲面未产出数、记录字段不完整数、保留/已输出/体列表独有曲面数、实体曲面引用访问数。所有比率仅针对本次枚举范围，不是独立认证的整个模型/薄壁/等厚覆盖率。

限制：128实体、10000唯一曲面、40000实体曲面引用、30秒软预算。时间在循环边界检查，无法中断单次阻塞SDK调用，不能承诺30秒硬超时；达到限制保留PARTIAL、truncationReason和已采记录。枚举API本身也可能耗时，不能为了超时把模型API丢到后台线程。

终结状态：无受支持活动零件为BLOCKED；观察身份/dirty变化优先标OBSERVED_IDENTITY_OR_DIRTY_CHANGE；不可恢复流程异常为FAILED；达到限制、字段/归属/身份/单位/默认体/精度缺失、错误或覆盖不足为PARTIAL；仅在所需读取及模型范围核对完整时COMPLETED_READS_ONLY。即便后者也不表示薄壁识别、等厚、无写入独立证明或转换成功。modelWriteAbsenceIndependentlyProven固定false。

未采点/法向/距离的理由为POINT_NORMAL_DISTANCE_COLLECTION_DEFERRED、samplingCoverage=NOT_REQUESTED_STEP_1，不将步骤二未做当成本步骤采样失败或成功。日志验证不填现有冻结schema的PASS；这是单独版本化P1_NATIVE_READONLY_GEOMETRY_V1导出契约。
