## 实现

1. 先按同一次采样的Step5算法，在质量池首次达到9点时冻结原选择。接着完成原32次质量追加预算内的后续候选，不再在9点池满时直接结束。候选池上限明确改为35（原3点+最多32新有效点），最终每面仍≤3，原生尝试总上限仍3000，非共线门槛不变。
2. 选择新三点时必须保留原固定非共线标志，并要求三角形面积不少于同轮冻结的Step5选择；冻结三点始终留在只追加的候选池中。没有合格改进/数值未知则保留冻结点。最多枚举C(35,3)=6545个组合，面积优先、最小点距同分排序。不保证最小点距或q也单调增加，不把三角形当材料覆盖。
3. 增加126个既有Step5平面指标参考，以及原16组的Step4面积参考；只用于跨轮诊断比较，不用历史坐标选点。文件名/版本戳/单位匹配只是已观察字段匹配，明确不是跨轮身份认证。记录当前q/距离/面积/UV指标及面积比例。
4. 用本轮最终原生有效点和法向采集同体同类型PLANE_PLANE、CYLINDER_CYLINDER粗配对证据：类型、采样法向点积关系、公共切平面的采样投影矩形重叠候选。无新SDK方法，不计算面间法向分离、半径差、最终厚度或等厚；不确认真实相对面，圆柱轴线/半径/同轴性与实际修剪重叠均UNKNOWN。
