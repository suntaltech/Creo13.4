# 修剪域见证、局部距离与范围

Step6的263个粗提示只基于法向和三点投影框，不是厚度对应。本轮先保留原64条/类型的粗输出，再每类型选择其中首次16条，按平面/圆柱交错验证。不是全部263对、不是最近/最佳排名，也不覆盖被旧输出上限省略的135对。

## 提议位置

平面对：两面各3个最终原生点作为源点，加5个公共投影交框内网格提议（中心、四个1/4与3/4组合），最多11个位置。网格位置只是支撑平面上的数值提议，可能落入孔/边界/修剪外部；不能因来自投影交框就接受。

圆柱对：两面各3个最终点，最多6个位置。依据目标候选轴/半径作径向映射；非同轴时仍只称局部映射点距离，不将它称为源面法向距离或最小距离。未重建圆柱角向/轴向完整修剪区域，相关覆盖UNKNOWN。

## 每个实际源/目标点的原生验证链

1. 在同一活动零件上下文构造Point3D输入参数；调用该面的原生EvalParameters，要求两个UV有限。
2. VerifyUV请求UV必须PLACE_INSIDE(0)，边界(1)/域外(2)/未知都拒绝。
3. Eval3DData后GetParams必须与刚才请求UV精确一致，不周期规范化/夹紧/自动外推；再次VerifyUV返回UV仍必须INSIDE。
4. 读取原生GetPoint/GetNormal，点有限、法向有限非零且归一化；原生XYZ与提议XYZ须在明确浮点护栏内回读一致，过大误差拒绝，不用最近点接口替换。
5. 源点先重新验证，之后才按目标解析候选投影并验证目标点。只有两面都成功才记录PAIR_LOCAL_DISTANCE_WITNESS，关联两条原生链序号、实际点/法向、映射来源、单位和距离。

原采样点也重新验证，不把旧有效性无条件沿用为新阶段成功。失败的源点不继续目标；目标失败不产出距离。双原生INSIDE在源与目标各执行一次完整链，因此一个成功距离见证有两条独立点验证链。

## 三种不同量

- PAIR_ANALYTIC_GAP_CANDIDATE：解析支撑平面偏移/数值同轴圆柱半径差候选，不包含真实修剪对应证明。
- PAIR_LOCAL_DISTANCE_WITNESS.localPointDistance：两个经原生验证的对应点的欧氏距离。平面按目标支撑平面法向映射，圆柱按目标轴径向映射，不是任意修剪域上的全局最小值。零距离可表示重合位置，不能自动称为零壁厚。
- finalWallThickness：始终NOT_ASSESSED。没有沿连线检查材料占据、其他表面遮挡、内外拓扑、双侧覆盖、圆柱完整角/轴域或全模型一致性；局部距离相同也不认证等厚。

成功见证说明所选位置的两面原生修剪域内对应，不能证明完整连续重叠区域。entireTrimmedOverlapRegionProven=false、trueOppositeFacesConfirmed=false保留。未找到见证不能证明无真实重叠，不能把网格/样本稀疏区域误判为无面、坏面或不薄壁。

每类型最多16对，共≤32；每个位置最多源/目标两条链，默认最多16×22+16×12=544条链，另有768链硬上限。链包含多次SDK调用，不是768次方法调用上限。30秒软预算与所有旧阶段共享，无法中断单个SDK调用；每个候选阶段也可能因预算而未验证，必须记录部分状态。
