# 失败分支、计数与Step6兼容

独立geometry-sampling-step7-UUID.jsonl，CREATE_NEW不覆盖旧日志；原schema、samplingSchema、samplingQualitySchema、selectionSchema、queueSchema、spreadSchema、pairSchema保持，collectorStep=STEP_7，追加distanceSchema=P1_NATIVE_ANALYTIC_LOCAL_DISTANCE_V1。原采样/选点方法和全部7个纯类仅命名空间变化，已逐段散列核对；原126组/16组结果仍待新运行回归验证，不预填成功。

新增事件：ANALYTIC_PARAMETERS_STARTED、SURFACE_ANALYTIC_PARAMETERS、ANALYTIC_PARAMETERS_SUMMARY；LOCAL_DISTANCE_ANALYSIS_STARTED、PAIR_ANALYTIC_GAP_CANDIDATE、PAIR_DOMAIN_POINT_EVALUATION、PAIR_LOCAL_PROBE_REJECTED、PAIR_LOCAL_DISTANCE_WITNESS、PAIR_OVERLAP_VALIDATION_SUMMARY、LOCAL_DISTANCE_ANALYSIS_SUMMARY。

采样attempts/acceptedSamples仍只统计旧采样；新域验证用domainEvaluationOrdinal/domainEvaluationChains/domainAccepted/domainRejected单独计数，不增加POINT_NORMAL_SAMPLE配额。某个有效源点可能没有有效目标，所以domainAccepted不等于距离见证数的2倍。成功距离须用两条链序号回查完整门禁；中间点、粗候选和距离见证不能再加到666个原点上。

解析失败：描述符null/异常、公共类型不匹配、框架/轴不可用、非有限半径/非正半径、坐标轴非正交、3个原生样本残差/法向不一致、单位未知，都使usableForLocalProjection=false；SURFACE_ANALYTIC_PARAMETERS保留原值和失败。非有限向量/半径以显式字符串而非非法JSON数字输出。分析未访问的面单列notVisited，不填0假装已读成功。

域验证失败包括：非有限提议、参数对象不可用、EvalParameters失败/非有限、请求UV非INSIDE、预算不足、Eval3DData/GetParams失败、返回UV不精确、返回UV非INSIDE、原生点/法向缺失或非有限、零法向、XYZ回读误差超过浮点护栏。每条已开始的链有唯一accepted/rejected处置及原因；不以改变模型精度、放宽边界或自动重试替代失败。

解析参数不可靠时该对PAIR_OVERLAP_VALIDATION_SUMMARY为UNKNOWN_ANALYTIC_PARAMETERS，不生成猜测间隙或见证。无双域内见证为NO_INTERIOR_WITNESS_NOT_PROOF_OF_NO_OVERLAP；预算/调用链上限中止为PARTIAL_DOMAIN_PROBING。无候选则NO_SELECTED_CANDIDATES_DISTANCE_UNKNOWN，不能解释为没有相对面。

旧READ_EXCEPTION/READ_UNAVAILABLE仍保留，新接口可能增加errors/unknownReadValues；不能写死旧4条未知。所有候选/原生点与距离仍PENDING_FINAL_COLLECTION_SUMMARY；模型状态变化导致整轮身份失效，不得单凭局部成功忽略。原revision未知不换成版本戳，整体严格条件不因新增见证而放宽。

若IO/采集异常提前中止，摘要或链的最终处置可能缺失，应视为不完整证据，不能补造成功或用0替代未执行。

COLLECTION_SUMMARY追加解析阶段完成/未知数、新域链计数、localDistanceEvidenceState/truncated及最终壁厚/全区域未知标记。新阶段未进入、中止或参数缺失时保持PARTIAL/UNKNOWN；COMPLETED_READS_ONLY即使将来出现也只是读取完成，不是厚度或转换合格。
