# 有界细化与四面结果

## 适用范围与上限

本案例模型叶名200002100.prt、指定ID2710/2738/2752/2843、真实SurfaceType=PLANE三者同时满足，才选择细化策略。ID以当前模型为范围，模型名/ID匹配不是对原模型几何身份的独立认证；仍核对本轮原生身份/版本戳、dirty、单位及实际类/SDK身份。其他模型或非PLANE不自动套用本案例规则。

基础25候选与Step2相同。基础未达3点时才进入追加候选；已达配额不额外细化。追加集合采用15个内部参数比例的组合：1/1024、1/256、1/64、1/32、1/16、1/8、1/4、1/2及对称近上界比例，共15×15=225个位置；排除原25及浮点重复后，最多新增200个。优先依次探测若干层的分散角部和边缘中部，再补其余组合，不简单按一条边连续扫。

这些比例只改变候选位置，不是新的几何容差。始终不取参数边界0/1，不夹紧或外推；浮点折叠后仍由原生VerifyUV判定，PLACE_ON_BOUNDARY/OUTSIDE、null、异常都拒绝。返回UV与请求不同也拒绝，不自动做周期规范化。

全局仍为最多300目标面、3000候选尝试、900接受点、每面目标3点和30秒软预算。4面新增至多800候选，仍受全局上限约束；不是在3000之外额外给800。软预算不能中断单次SDK调用。候选耗尽不证明面无有效域、不薄壁或损坏，不通过放宽门禁追求100%。

## UV记录

每个实际进入基础曲面处理的保留面输出SURFACE_UV_RANGE，包含原生索引顺序u0/u1/v0/v1、rawUvExtentValues、来源、是否有限严格递增、是否modelListed。非有限值以明确字符串保存，缺值UNKNOWN；不排序修复反向范围或猜测周期区间。modelUvRangeCoverage只对模型枚举分母统计数值有效范围，不代表有效修剪域覆盖。

数量/时间限制导致未处理的面无法获得范围，使用未产出计数和截断原因，不为“每个面”补造范围。实际采样的SURFACE_CANDIDATE_PLAN复用缓存值并列基础/追加候选数；SURFACE_REFINEMENT_STARTED只在真正进入追加候选时输出。

## 失败分支

无单位、范围缺失/无效/退化、读取异常时保留原因，不进入有效点接受路径；模型/类型不匹配不细化。请求UV非INSIDE、求值/返回UV失败或不一致、返回点非INSIDE、非有限点/零或非有限法向、重复XYZ继续按Step2拒绝。追加候选仍不足则记录BASE_AND_REFINEMENT_EXHAUSTED_QUOTA_NOT_MET。全局限制/预算与流程中止单独记录，不伪装成全部候选已正常求值。

本阶段不保证4面必定补到点；若仍失败，新UV范围与逐候选原生判定将作为后续域内种子/轮廓方法研究的依据。未实现额外SDK轮廓或最近点求解，不臆造相关调用。
