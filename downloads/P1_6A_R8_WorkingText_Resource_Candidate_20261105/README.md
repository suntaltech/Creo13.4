## controlled.dat.template

占位符模板保持startup java、BatchRename、allow_stop true、delay_start false。classpath需替换为已有、独立且身份已核对的R7业务class目录；text_dir占位符需替换为本候选解压目录，其后已明确拼接working-text-layout。模板含占位符，不能原样注册；确认目标平台路径表示、转为有效绝对路径后，方可在后续已授权的受控环境使用。本轮未创建可执行dat或改生产配置。

该模板未承诺全局加载无其他活动：冻结业务启动流程已有CREOSON异步启动机制，既有日志port listening不证明服务身份或就绪。本包不改变该逻辑。
